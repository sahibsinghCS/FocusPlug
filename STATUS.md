- **Timer faces (2026-09-11).** Lock mode renders one of seven faces, picked from live previews on the panel: **Flight** (default), Hourglass, Column, Grid, Eclipse, Field, Readout. Flight turns the session into a real one — `routeForMinutes` matches great-circle block time against sixty bundled airports, deterministically, so a given length always draws the same pair. The globe is an orthographic canvas projection over Natural Earth 1:110m coastlines shipped in the bundle (`scripts/build-land.mjs` regenerates `assets/land.json`, 54 kB): no Mapbox, no token, no network — the CSP is `default-src 'self'` and nothing may leave the machine. Land vertices are precomputed as unit vectors so a frame is three dot products per point, which is what lets seven previews animate at once. Short hops zoom the projection into a circular porthole so a 377 km route is still readable while staying recognisably a sphere. Fixed: `formatSpan` rendered 7,199 s as “1h 60m”. The aircraft is a drawn airliner silhouette, and the globe now renders its fixed layers to an offscreen canvas once per route so a `requestAnimationFrame` loop can ease the plane continuously between the timer's 250 ms ticks instead of stepping with them.
- **Windows verification pass (2026-09-11).** Every stream was built and judged on Linux against simulated seams, so the two Win32-only paths had never run on Windows:
  - **Window sensor was dead on Windows.** `FOREGROUND_SCRIPT` used `$pid`; PowerShell variable names are case-insensitive and `$PID` is Constant + AllScope, so `[ref]$pid` threw every tick, the catch emitted an empty payload, and nothing ever matched the allow/blocklists — no **On task**, no **Distracted**, no window-triggered kill or unlock. Renamed to `$fgPid`; the script now reports its own faults on stderr instead of failing silently. Guarded by `src/main/window/win32.test.ts` (reserved-variable check + a live run of the real script) and `npm run probe:window:live`.
  - **Live kill probe never ran on Windows.** The stand-in was `timeout.exe`, which exits under redirected stdio, so all three live tests failed here while passing in Linux CI. Now `ping.exe`; `npm run test:kill` is **25/25 on Windows**, exercising real `tasklist` / `taskkill` plus the chrome-stand-in refusal.
  - **New pre-flight: `npm run probe:golden`.** Drives the production wiring (`createSessionRuntime` — platform reader, store, policy, killer) against the live focused window and asserts **On task**; allowlist comes from the focused window and the blocklist matches nothing, so it can never terminate a real process. Verified on Windows: `focusSnapshots=12 matchedAllow=10 decision=ON_TASK kill events=0`.
  - `docs/screenshots/` generated (`npm run stills:readme`), so the README images resolve. `puppeteer-core` is now a declared devDependency — the stills scripts imported it without it being in `package.json`.
- **Adaptive fuse wired in (2026-09-12).** `src/shared/adapt` was a tested island — nothing in `src/main` or `src/renderer` imported it, so the countdown was still the fixed Settings value.
