# FocusPlug — Full MVP Spec

## One-liner
Local study-session enforcer: detect leave-assignment (window + AI desk presence), force-quit Discord/games, unlock only when back on task. Never kill the study PC. Not a tutor.

## Golden path (90s)
Start session (Docs/Chrome allowlisted) → open Discord → Distracted + desk status + 10s countdown → Discord killed → return to Docs + at desk → Unlocked. **Demo Kill** for filming.

## Must ship
Session start/stop · allowlist · blocklist · window detector · AI desk-presence (load-bearing) · countdown · kill/block · unlock · Demo Kill · polished dark UI · session log · README + demo script + AI disclosure blanks

## Out
Tutor/chat · phone spyware · power off study PC · Convex rewrite · smart-plug must-have (stretch stub OK)

## Policy v1
Session OFF = observe only. Session ON + blocked focus → countdown → kill. Desk away (high conf) → countdown → kill running blocklist apps only. Uncertain desk → no desk-only kill. Return to allowlist + desk present → cancel/unlock.
