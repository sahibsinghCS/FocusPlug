# Independent critic (Phase 3 final visual integration)

Blind critic (no builder rationale). Bar: 1280×800 before/after of the **whole console** (Session + one config page + Logs + overlay). Select which set is one shippable enforcement product vs four Phase 3 streams taped together. Overlay must stay cinematic; Demo Kill and plug consequence must stay readable.

Stills compared: `before-*` vs `after-*` in this folder (session idle/live/overlay, allowlist, plugs, settings, log empty/golden). Critic was not told which prefix is new.

## Verdict: WIN

- **Selected console:** AFTER
- **Selected overlay:** AFTER (tie on composition; AFTER does not regress the fuse)

**Largest gap on the loser (BEFORE):** Four different page languages. Titlebar says Plugs / Log / Settings while the canvases say Outlets / Smart plugs, Timeline / Session log, Policy / Settings. Session adds a third name (Command center). Log actions are raw chips; config uses lime Add; session uses a unique header row. Settings Preview overlay sits below the 800px fold. It reads as four PRs, not one console.

**Why AFTER:**

- Sidebar, titlebar, and page H1 use the same words (Allowlist, Blocklist, Plugs, Settings, Log).
- Shared header / panel / empty / error / GhostButton / status-tone tokens. Log empty and Session timeline empty now say the same thing: start a session to record the chain.
- Session drops the extra Command center chrome; Decision remains the billboard; Demo Kill stays secondary-danger.
- Settings Preview overlay is on-canvas at 1280×800.
- Overlay still: huge `08`, Killing blocked apps in, APP KILL + PLUGS CUT (Desk lamp), Demo Kill — skip wait. Not a toast.

**Largest remaining ding (not a loss):** Log is still a workspace (filters + 90s rail) while config is a 920px form. That is the right IA. Density is tight with the path open, not a second product.

**Haven / AGPL:** original FocusPlug UI. No Haven source or assets.

**Checks:** `npm test` (221) and `npm run typecheck` pass. Browser walk at 1280×800: Session, Allowlist, Blocklist, Plugs, Settings, overlay, Demo Kill, `#/log?scene=golden`, status-pill and sensor-card navigation.
